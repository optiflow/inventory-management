Factory Inventory Management System

A full-stack demo application for tracking inventory, orders, demand forecasts, spending, and backlog across multiple warehouses — built with a Vue 3 single-page frontend and a Python FastAPI backend serving in-memory mock data.

Vue 3 · Composition API FastAPI · Pydantic In-Memory JSON Data Bilingual (EN / JP) No Database

3 Data Flow

Example: a user filters inventory by warehouse and category. The request travels from reactive UI state through the API client to the backend and back.

1

User interaction → reactive state

A filter is changed in FilterBar.vue. The shared useFilters composable updates refs like selectedLocation and selectedCategory. A watch() detects the change.

2

API client builds the request

getCurrentFilters() maps UI state to API params (location → warehouse, period → month). api.js issues GET /api/inventory?warehouse=Tokyo&category=all via Axios.

3

FastAPI endpoint handles the request

The route in main.py receives typed query params. apply_filters() filters the in-memory list (skipping any param equal to "all"); filter_by_month() handles month/quarter logic for orders.

4

Pydantic validates & serializes

Results are validated against the response_model (e.g. List[InventoryItem]) and serialized to JSON. Mismatches surface as errors before reaching the client.

5

Frontend renders derived data

Axios resolves response.data into raw refs. computed() properties derive filtered/formatted views (currency, i18n translations) that render reactively in the table.

5 Domain Model & Frontend Organization

Pydantic models define the backend contract; composables centralize cross-component state on the frontend.

Pydantic Models

  • InventoryItem — sku, category, warehouse, quantity_on_hand, reorder_point, unit_cost
  • Order — order_number, customer, items[], status, dates, total_value
  • DemandForecast — item, current vs forecasted demand, trend
  • BacklogItem — shortage qty, days_delayed, priority, has_purchase_order
  • PurchaseOrder — supplier, quantity, unit_cost, expected_delivery, status

Frontend Composables & State

  • useFilters — global filter refs (period, location, category, status) + param mapping
  • useAuth — mock current user, profile, and per-user tasks
  • useI18n — EN/JP locale, auto currency (USD/JPY), translation helpers
  • Reactivity pattern — raw data in ref(), derived views in computed(), refetch via watch()
  • Data store — no Vuex/Pinia; shared singletons via composables
